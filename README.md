## 🏃 Local Development

```bash
# Clone the repository
git clone https://github.com/metiinie/My_Personal_Portfolio.git
cd My_Personal_Portfolio

# 1. Start Backend Server
cd backend
cp .env.example .env   # Add your GEMINI_API_KEY (or leave blank to use the built-in AI persona)
npm run dev

# 2. Start Frontend Application (in a new terminal)
cd frontend
npm install
npm run dev

# Build production frontend bundle
npm run build
```
